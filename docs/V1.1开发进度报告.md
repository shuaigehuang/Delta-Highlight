## 一、迭代概述

V1.0 实现了命令行 Pipeline，V1.1 在此基础上增加**图形化 Web 界面**、**镜头脚本可视化编辑**和**完整的工作流体验**。

## 二、新增模块

### 2.1 Express Web 服务 (`src/server.js`)

| 功能 | 说明 |
|------|------|
| Pipeline 编排 | 直接调用各模块，分 5 步执行：发现视频 → 扫描 → 日志 → 裁剪 → 拼接 |
| 逐视频状态追踪 | `videos[]` 数组跟踪每视频的 scanStatus / clipStatus |
| SSE 实时推送 | 13 种事件类型：init / video-scan-start / video-scan-done / video-clip-start / video-clip-done / timer / step / done / error 等 |
| 停止机制 | `POST /api/stop` 设置 aborted 标志 + kill 活跃子进程 |
| 计时器 | 每秒推送 elapsed，前端实时显示 |
| 加载镜头脚本 | `POST /api/load-shotlog` 支持路径或 JSON 内容（拖拽），完整校验链 |
| 目录浏览 | `GET /api/dirs?path=` 返回子目录列表，前端逐层浏览 |
| 错误处理 | 全局 `/api` 错误处理器，确保 API 错误返回 JSON 而非 HTML |

**API 端点清单（共 10 个）：**

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/events` | GET | SSE 进度推送 |
| `/api/scan` | POST | 启动全流程 |
| `/api/stop` | POST | 停止当前流程 |
| `/api/load-shotlog` | POST | 加载并校验镜头脚本 |
| `/api/set-material-dir` | PUT | 设置素材目录 |
| `/api/shotlog` | GET | 获取当前镜头日志 |
| `/api/shotlog` | PUT | 保存编辑后的镜头日志 |
| `/api/frame` | GET | 提取帧缩略图 |
| `/api/reclip` | POST | 重新裁剪+拼接 |
| `/api/output` | GET | 获取成品信息 |
| `/api/dirs` | GET | 浏览目录结构 |

### 2.2 Web 前端 (`web/`)

| 技术 | 选型 |
|------|------|
| 框架 | **Vue 3 CDN**（零 npm 依赖） |
| 进度 | **SSE** (Server-Sent Events) |
| 样式 | 暗色主题 CSS |
| 端口 | `http://localhost:3456` |

**三个标签页：**

| 标签页 | 功能 |
|--------|------|
| 🔍 扫描剪辑 | 目录浏览/粘贴 → 视频列表表格 → 逐视频扫描/裁剪状态 → 计时器 → 停止按钮 → 成品信息 |
| ✏️ 镜头编辑 | 加载 shotlog（拖拽/浏览/粘贴路径） → 帧缩略图 → 可编辑裁剪范围/击杀时刻 → ↑↓排序 → 🗑删除 → 保存 → 重新生成 |
| 🎬 预览 | 预留，显示成品路径 |

### 2.3 镜头脚本格式升级

```json
{
  "version": "1.1",
  "materialDir": "C:/.../03-素材/20260713-20260726",
  "config": { "beforeSeconds": 5, "afterSeconds": 2, "mergeMaxGapSeconds": null },
  "generatedAt": "2026-07-26T...",
  "totalClips": 12,
  "clips": [
    {
      "sourceFile": "Delta Force 2026.07.13 - 21.03.53.03.DVR.mp4",
      "killTimes": [26.217],
      "maxConfidence": 0.9475,
      "clipStart": 21.217,
      "clipEnd": 28.217,
      "duration": 7.0,
      "mergedFrom": 1
    }
  ]
}
```

**V1.1 新增字段：** `materialDir` — 记录素材目录，支持后续一键重新加载。

## 五、关键 Bug 修复记录

| 问题 | 根因 | 修复 |
|------|------|------|
| 对话框在编辑页看不到 | 模态框在 `#app` 外部，Vue 无法控制 | 移至 `#app` 内部 |
| 加载镜头脚本失败 | 键名不匹配 (`needMaterialDir` vs `needDir`) | 统一为 `needDir` |
| 加载时只能粘贴路径 | 无拖拽/浏览功能 | 新增拖拽区 + 文件选择器 + `shotlogContent` 传输 |
| 保存时报 JSON 解析错误 | 拖拽加载时 `shotlogPath` 为 undefined，`fs.writeFileSync(undefined)` 崩溃返回 HTML 500 | 自动推导 shotlogPath + 全局 JSON 错误处理 |
| 扫描后日志无击杀 | `buildScanResult()` 生成空 `detections` | 改为读取 Python 实际输出的 scan-result JSON |
| 素材目录只能粘贴路径 | 无浏览功能 | 新增 `/api/dirs` + 目录浏览器弹窗 |
| SSE init 事件丢失 | SSE 连接未就绪时即推送 | 增加 500ms 延迟 |
