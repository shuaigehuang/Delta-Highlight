## 一、新增需求

### 1.1 修复文件夹选择体验

**背景**：V1.3 通过 PowerShell 拉起 `FolderBrowserDialog` 存在严重体验问题：
- 对话框不置顶，被浏览器窗口遮挡
- 需要最小化浏览器才能操作
- 旧式树形对话框无法粘贴路径

**方案**：移除 PowerShell 原生对话框，回归 Web 内目录浏览器并大幅改进：

| 改进项 | 说明 |
|--------|------|
| 恢复文本输入框 | 可直接粘贴路径，失焦或回车时校验路径是否存在 |
| 目录浏览器增加路径栏 | 顶部显示当前路径，可编辑后点"前往"跳转 |
| 目录浏览器显示文件 | 不仅列子文件夹，还显示当前目录下的文件（便于确认） |
| 移除 `/api/pick-dir` | 删除 PowerShell 相关代码 |

### 1.2 镜头脚本包含无击杀视频

**背景**：部分无击杀视频也包含有价值内容（如精彩操作、队友配合），保留在镜头脚本中可手动选择保留。

**规则**：
- 扫描后生成镜头脚本时，无击杀视频也生成一条记录
- 无击杀片段：`clipStart=0, clipEnd=0, duration=0, killTimes=[], noKill=true`
- 新增 `videoDuration` 字段记录视频实际时长（供编辑时参考）
- 视频生成时自动跳过 `duration=0` 的片段
- 用户在编辑页手动设置裁剪范围后，该片段参与生成

**前端编辑页**：
- 无击杀片段显示灰色样式 + "⚪ 无击杀" 标签
- 显示视频实际时长，方便手动设置范围
- 校验逻辑：`duration=0` 的片段不报错（允许保持跳过状态）

### 1.3 音频处理标签页（背景音乐混合）

新增第四个标签页 "🎵 音频"：

| 控件 | 说明 | 默认值 |
|------|------|--------|
| 启用背景音乐 | 勾选框 | 不勾选 |
| 音乐文件 | 文件选择器（mp3/wav/aac/flac） | 无 |
| 原视频音量 | 数字输入，-30 ~ +10 dB | 0 dB |
| 音乐音量 | 数字输入，-30 ~ +10 dB | -10 dB |

**ffmpeg 实现**（高效直出模式）：

```bash
ffmpeg -f concat -safe 0 -i list.ffconcat \
       -stream_loop -1 -i music.mp3 \
       -filter_complex "[0:a]volume=0dB[va];[1:a]volume=-10dB[ma];[va][ma]amix=inputs=2:duration=first:dropout_transition=2[aout]" \
       -map 0:v -map "[aout]" \
       -c:v libx264 ... -c:a aac -y output.mp4
```

- `-stream_loop -1`：音乐无限循环
- `amix=duration=first`：以视频时长为准
- `dropout_transition=2`：结尾 2 秒淡出

**音乐文件传递**：前端通过文件选择器读取 → Base64 上传 → 服务端保存到工作目录 `music/` 下。

### 1.4 时间戳命名

**镜头脚本文件名**：生成时自动命名为 `shotlog-YYYYMMDD-HHmmss.json`（如 `shotlog-20260727-143025.json`）。

**输出视频默认文件名**：输出设置对话框中默认文件名为 `highlight-YYYYMMDD-HHmmss.mp4`（如 `highlight-20260727-143025.mp4`），360P 预览时追加 `_preview`。

## 二、技术决策

| 决策 | 说明 |
|------|------|
| 文件夹选择 | 移除 PowerShell，改进 Web 目录浏览器（路径栏可编辑 + 显示文件） |
| 无击杀片段 | `duration=0` + `noKill=true` 标记，生成时 filter 跳过 |
| 音频混合 | ffmpeg `amix` + `stream_loop`，在最终编码阶段统一混入 |
| 音乐上传 | `POST /api/upload-music`，Base64 → 保存到工作目录 |
| 时间戳命名 | `YYYYMMDD-HHmmss` 格式，前端生成（`new Date()`） |
| shotlog 版本 | 升级为 `1.3` |
