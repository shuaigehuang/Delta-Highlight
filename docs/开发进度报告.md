## 二、已实现功能

### 2.1 视频击杀扫描 (`prototype/scan_video_only.py`)

纯 Python 脚本，不依赖音频预筛选，直接在视频全片中搜索击杀 UI 图标。

| 项目 | 规格 |
|------|------|
| 模板 | 3 个：白色击杀 / 橙色载具摧毁 / 橙色精准击杀 |
| 搜索区域 | 3840×2160 屏幕，ROI (1423, 1432) 1000×100 px |
| 采样 | 每 0.2s 一帧 (5fps) |
| 阈值 | 0.7 (TM_CCOEFF_NORMED) |
| 去重 | NMS 空间去重 + 位置感知时间窗口合并 (3s) |
| 视频接入 | OpenCV 直接读取 DVR mp4，无需 ffmpeg 预提取 |
| 中文路径 | 使用 `cv2.imdecode` 绕过 OpenCV 中文路径问题 |
| 输出 | JSON，含每帧检测详情（时间戳、位置、置信度、模板类型） |

**实测数据：**

| 批次 | 视频数 | 有击杀 | 总击杀 | 耗时 |
|------|--------|--------|--------|------|
| 06.28~07.12 | 13 | 12 | 43 | ~7 min |
| 07.13~07.26 | 16 | 12 | 36 | ~8 min |

### 2.2 镜头日志 (`src/lib/shotlog.js`)

从扫描结果生成剪辑计划。

```json
{
  "sourceFile": "Delta Force 2026.07.19 - 20.39.15.03.DVR.mp4",
  "killTimes": [18.333, 18.517, 18.7, 19.067, 22.183, 24.75],
  "maxConfidence": 0.986,
  "clipStart": 13.333,
  "clipEnd": 26.75,
  "duration": 13.417,
  "mergedFrom": 6
}
```

| 功能 | 说明 |
|------|------|
| 合并规则 | 同一视频的所有击杀合并为 1 个片段（不拆分） |
| 裁剪范围 | `[最早击杀 - 5s, 最晚击杀 + 2s]`，边界 clamp 到视频起止 |
| 击杀标记 | `killTimes[]` 记录片段内所有击杀时间点，方便人工微调 |
| 置信度 | `maxConfidence` 记录片段内最高置信度 |
| 最小片段 | < 3s 自动扩展到 3s |

### 2.3 视频裁剪 (`src/lib/clipper.js`)

| 项目 | 规格 |
|------|------|
| 引擎 | ffmpeg |
| 视频编码 | libx264, CRF 18, preset medium |
| 音频编码 | AAC |
| 加速 | 可选 NVIDIA NVENC (`h264_nvenc`) |
| 批量 | `clipAll()` 按 shotlog 批量裁剪，进度报告 |

### 2.4 视频拼接 (`src/lib/concat.js`)

| 项目 | 规格 |
|------|------|
| 方式 | ffmpeg concat demuxer |
| 单片段优化 | 仅有 1 个片段时直接复制，不重编码 |
| 清理 | 自动删除临时 concat 列表文件 |

### 2.5 一键 Pipeline (`prototype/run-pipeline.js`)

```
素材目录 → [Step 1: scan] → [Step 2: shotlog] → [Step 3: clip] → [Step 4: concat] → 成品
```

| 特性 | 说明 |
|------|------|
| 断点续跑 | `--from-shotlog` / `--from-clips` 跳过已完成步骤 |
| 扫描缓存 | 已有扫描结果则自动跳过（删文件可强制重扫） |
| 素材目录 | `--material-dir` 指定任意目录 |
| 自动命名 | 从素材日期范围生成成品名，如 `highlight-20260713-20260726.mp4` |
| 参数覆盖 | `--threshold` `--interval` `--before` `--after` |

## 五、使用方法

```bash
cd 02-代码/delta-highlight

# 完整流程（默认扫描 03-素材/）
node prototype/run-pipeline.js

# 指定素材目录
node prototype/run-pipeline.js --material-dir "../../03-素材/某个子目录"

# 仅扫描
node prototype/run-pipeline.js --scan-only --material-dir "../../03-素材/..."

# 跳过扫描（已有结果）
node prototype/run-pipeline.js --from-shotlog
```
