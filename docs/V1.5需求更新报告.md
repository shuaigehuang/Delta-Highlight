## 一、配置文件 (config.json)

### 1.1 问题

当前 ffmpeg 路径、Python 路径、默认输出目录等全部硬编码为开发者个人路径（共 10 处），其他人无法运行。

### 1.2 方案

新增 `config.json`，首次启动时若不存在则自动生成模板：

```json
{
  "ffmpegPath": "ffmpeg",
  "pythonPath": "python",
  "outputDir": "./output",
  "materialDir": "",
  "port": 3456
}
```

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `ffmpegPath` | ffmpeg 可执行文件路径，`"ffmpeg"` 表示 PATH 中查找 | `"ffmpeg"` |
| `pythonPath` | Python 可执行文件路径，`"python"` 表示 PATH 中查找 | `"python"` |
| `outputDir` | 成品输出目录 | `"./output"` |
| `materialDir` | 上次使用的素材目录（前端 localStorage 也会记录） | `""` |
| `port` | Web 服务端口 | `3456` |

### 1.3 改动点

| 文件 | 改动 |
|------|------|
| `src/server.js` | 启动时加载 config.json（不存在则生成模板）；`FFMPEG_PATH`、`PYTHON_CMD`、`FINAL_DIR`、`PORT` 从配置读取 |
| `src/lib/clipper.js` | `FFMPEG_PATH` 改为从外部传入或读取配置 |
| `src/lib/concat.js` | 同上 |
| `web/app.js` | 默认输出目录从 `/api/config` 获取，不再硬编码 |
| `src/server.js` | 新增 `GET /api/config` 返回前端需要的配置（outputDir 等） |

### 1.4 首次启动体验

```
$ npm start
⚠️ 未找到 config.json，已自动生成模板。
   请编辑 config.json 配置 ffmpeg 和 Python 路径后重新启动。
   如果 ffmpeg / python 已在系统 PATH 中，无需修改即可使用。
```

## 二、代码清理

### 2.1 删除弃用的音频模块

以下文件为早期音频检测方案遗留，已完全不被任何活跃代码引用：

| 文件 | 原用途 |
|------|--------|
| `src/lib/audio.js` | 音频提取 |
| `src/lib/detector.js` | 波形互相关 |
| `src/lib/spectral-detector.js` | 频谱匹配 |
| `src/lib/multi-sample.js` | 多样本特征 |
| `src/lib/wav.js` | WAV 解析 |
| `src/lib/video-detector.js` | 早期 Node→Python 调度 |
| `src/lib/detect_kill_ui.py` | 早期 Python 模板匹配 |
| `kill-sounds/` 目录 | 击杀音效模板 |

### 2.2 删除历史测试脚本

`prototype/` 下仅保留 `scan_video_only.py`（被 server.js 直接调用），其余全部删除：

| 删除 | 说明 |
|------|------|
| `run-test.js` ~ `run-test-v7.js` | 各阶段音频方案验证脚本 |
| `diagnose.js` / `diagnose2.js` / `diagnose3.js` | 诊断脚本 |
| `debug-gt.js` / `quick-diag.js` / `cross-check.js` | 调试脚本 |
| `run-pipeline.js` | V1.0 CLI 流程（已被 server.js 取代） |

### 2.3 移动核心扫描脚本

`scan_video_only.py` 从 `prototype/` 移到 `src/` 下（它不再是原型，而是核心组件）：

```

```

`server.js` 中 `SCAN_SCRIPT` 路径相应更新。

### 2.4 移动模板图片

击杀 UI 模板图片从策划目录移入项目内部：

```
01-策划/原型测试/视频检测辅助工具/01-击杀图标（白色部分）.png  →  templates/01-kill-white.png
01-策划/原型测试/视频检测辅助工具/02-摧毁载具图标（橙色部分）.png  →  templates/02-vehicle-orange.png
```
